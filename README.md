# Rishi's Quiz App 

An interactive web-based trivia quiz application built with HTML5, CSS3, and Vanilla JavaScript. Test your general knowledge against the clock with instant visual feedback and score tracking!

##  Features

* **Interactive Gameplay**: The questions are rendered with a proper numbering .
* **Question Timer**: It has a  15-second countdown timer for each question that automatically locks options if time runs out.
* **Instant Feedback**: It has a immediate colour coded feedback like here green is for correct and red is for incorrect 
* **Score Tracking**: Tracks your overall score and provides a summary at the end with a "Play Again" option.
* **Welcome Animation**: A simple and nice welcome animation welcomes teh application
* **Custom 404 Error Page**: A themed fallback page for missing routes or broken links.
