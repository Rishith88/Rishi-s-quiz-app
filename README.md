# Rishi's Quiz App 

An interactive web-based trivia quiz application built with HTML5, CSS3, and Vanilla JavaScript. Test your general knowledge against the clock with instant visual feedback and score tracking!

##  Features

* **Interactive Gameplay**: Dynamically rendered questions and answer buttons.
* **Question Timer**: A 15-second countdown timer for each question that automatically locks options if time runs out.
* **Instant Feedback**: Immediate color-coded feedback (Green for correct, Red for incorrect) when an option is selected.
* **Score Tracking**: Tracks your overall score and provides a summary at the end with a "Play Again" option.
* **Welcome Animation**: An animated introduction screen when launching the app.
* **Custom 404 Error Page**: A themed fallback page for missing routes or broken links.
